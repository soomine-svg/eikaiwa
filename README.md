# えいかいわのもり 🦜

話して覚える英会話れんしゅうアプリ（小学生向け・単一HTML PWA）。

- **かいわ**: 16場面のロールプレイ。アプリが相手役を音声で演じ、マイクで答えると音声認識で採点（Web Speech API・APIキー不要）
- **フレーズ**: 日常頻出フレーズ51本を「聞く→言う→✅」で練習
- **じこしょうかい**: 名前・年齢・好きなものから英語の自己紹介を自動生成して練習
- **きろく**: ⭐・クリア状況・ひっこしコード（機種変更時のバックアップ）

姉妹アプリ: [えいごのもり](https://github.com/soomine-svg/eigonomori)（英単語）

公開URL: https://soomine-svg.github.io/eikaiwa/

※音声認識はネット接続が必要な端末が多い。非対応端末では自動で「聞いてまねする」方式に切り替わる。
